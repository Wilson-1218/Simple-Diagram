# Simple Diagram 功能清單

手繪風格立體圖編輯器。應用位於儲存庫根目錄（`index.html` / `app.js` / `styles.css`）。  
目前版本：**v13.5.28**。

> **給維護者：** 使用者向更新說明（README「更新說明」）保持**精簡**——每版一行；`?` 面板不再列版本清單；細節只寫 Agent Store `internal/`。

工具列：**左側 3 直行網格**（可拖右緣調寬；窄時 2 直行；頂部品牌＋中EN＋日夜）＝**繪畫／構建／記號**（EN Draw／Construct／Marks）；**頂部 overlay**＝模板（含存成模板）／圖層／最近／編輯／Json／匯出；線型、弧／扇、記號、**長度**、填色、圖形、圓件、對齊為左側情境浮層。穩定版 **v13.5.28**。

## 功能

| # | 功能 | 用法 |
|---|---|---|
| 1 | **橢圓** | 繪製 → 橢圓 (E) |
| 2 | **扇形／弧段** | 繪製 → 扇弧 (A)；左欄 **弧｜扇**；`G` 在相關工具時切換 |
| 3 | **自選範圍匯出** | 「匯出 ▾」→ 框選匯出；預覽／PNG／SVG 只匯該區 |
| 4 | **匯出隱藏點** | 「匯出 ▾」內勾選（預設開） |
| 5 | **水平線／垂線／垂足／切線** | 構造：水平／垂線點選後拖曳定長；**垂足**先點一點再點線段（正交投影＋高線）；**切線**點圓周（或近圓周）後拖曳定長，垂直於半徑；端點可再拖調 |
| 6 | **雙網格** | 「圖層 ▾」內：網格開關＋方格｜三角格（預設三角格＋網格開；與 `layers.gridShow`／吸附聯動） |
| 7a | **Json ▾** | 頂欄 Json ▾：貼上／儲存／開啟 JSON（ops 陣列或完整圖檔）；AI 看本站 [`ai.html`](../ai.html) |
| 7 | **我的模板** | 頂欄「模板 ▾」內含**存成模板**（整圖→localStorage「我的／Saved」、更名／刪除／匯出 JSON）＋「如何接入 AI」；無內建組合；平面／立體見「圖形」 |
| 8 | **長度標註** | 浮層：字級、隨線｜水平、樣式 1 文字／2 尺寸線／3 弧括（平行弧＋中間數值，可選實／虛／點線）／4 端點弧；存於 `lengthLabels`；PNG／SVG／`addLength` 支援 |
| 9 | **快捷鍵可自訂** | `?`／`Ctrl+/`；可改鍵並存本機；衝突會標示；預設含填色 I、圖形 B、圓件 T；畫布**右鍵＝選取⇄上一工具**、**中鍵拖曳＝平移**；選取時 **+**（或 =）亦可回上一工具 |
| 10 | **標籤避線** | 新建標籤自動偏離附近線／圓 |
| 11 | **對齊輔助** | 拖點／畫線時顯示水平／垂直參考線；近等長提示 |
| 12 | **深色畫布** | 左欄 Logo 下日／夜圖示；僅編輯；**匯出仍白底黑線** |
| 13 | **最近檔＋自動備份** | 「最近 ▾」；定時備份；啟動可還原 |
| 14 | **優角／Reflex** | 記號 → 優角；畫 >180° 大弧；可標字母／度數 |
| 15 | **簡易座標圖** | 多曲線；對數底；軸刻度／數值（關則兩者皆隱，軸線與 O 仍在）；sin/cos/tan；圓一般式；曲線標籤；三角參數單位；**角度軸刻度**（π 直式分數／°）；原點只標 O；選取後拖角縮放 |
| 16 | **介面中／EN** | 左欄品牌下方 **中｜EN**（旁為日夜）；按鈕與工具提示同步；畫布數學不變 |
| 17 | **預設縮放 2×** | 首次開啟／清除／無相機 JSON；有存相機則沿用。清除**不重置**網格顯示／吸附／格模式 |
| 18 | **離開警告** | 僅未儲存編輯時；空白／已存／剛還原備份不提示 |
| 19 | **填色／Fill** | 繪製 → 填色 (I)；浮層：**多邊形｜扇形｜弓形**＋色票（灰影／藍灰／**白色**挖空）；後加的填色疊在上方；多邊形依序點頂點再點起點；扇形點既有扇或圓心→起→終；弓形同圓兩點；JSON `fills[]` 含 `kind`；白填 `color:"#ffffff", opacity:1` |
| 20 | **常用圖形／立體** | 繪製 → 圖形 (B)；浮層**圖示網格**（無文字）：平面形＋立體投影（立方體／長方體／直棱柱／圓台／四面體／正方錐／三棱柱／圓柱／圓錐）；外接框拖曳；浮層限制在視窗內並可內捲（底列可點）；ZH／EN tooltip；`addShape` 亦可放立體 |
| 21 | **弦／直徑／半徑** | 構造 → 圓件 (T)；浮層弦｜直徑｜半徑；在圓上拖曳；線型跟線段樣式 |
| 22 | **多選對齊／等距** | 選取≥2 可動物件時浮層：L/C/R/T/M/B、橫距／縱距、等長（≥2 線段） |
| 23 | **圖層顯示／鎖定** | 頂欄「圖層 ▾」：上方網格開關＋格種（單一控制）；列：座標／**記號**（顯示＋鎖定）。記號**預設鎖定**；座標鎖定＝不可選取／拖移座標圖 |
| 24 | **範本（我的）** | 模板選單僅使用者自存；單形立體／平面由圖形浮層；AI 仍可用 `insertTemplate`（plane/solid ids） |

### 座標對話框（摘要）

- **角度軸刻度**（預設關）：π／° 刻度；關閉還原數字刻度與視窗。
- **三角參數單位**：只影響 sin／cos／tan 的 Bx+C。
- 排版約 920px 兩欄；1–3 條曲線通常無列表捲軸。
- 弧度 π 刻度為直式分數；軸數值略過 ≈0。

## 簡短操作流程

1. 開啟 `index.html` 或 `simple-diagram-standalone.html`（標題應見 **Simple Diagram · v13.5.28**）。
2. 左側選工具；頂部 overlay「匯出 ▾」預覽或存檔。
3. Chrome／Edge 存檔可選資料夾；匯出不受深色畫布影響。
4. AI／自動化（v13.5：`insertTemplate`、macros、`export-diagram` SVG）：見 [`diagram-format.md`](diagram-format.md)、[`agent-draw-playbook.md`](agent-draw-playbook.md) 與 README「AI / Automation」（JSON＋ops，不模擬 UI；v13.5.0 起含扇／弓形填色與圖形／圓件／對齊 ops）。
