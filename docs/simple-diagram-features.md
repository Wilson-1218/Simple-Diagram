# Simple Diagram 功能清單

手繪風格立體圖編輯器。應用位於儲存庫根目錄（`index.html` / `app.js` / `styles.css`）。  
目前版本：**v13.2.1**。

工具列：**左側兩欄網格**＝繪製／構造／記號；**上方列**＝模板、屬性、檢視；匯出收進「匯出 ▾」。

---

## 功能

| # | 功能 | 用法 |
|---|---|---|
| 1 | **橢圓** | 繪製 → 橢圓 (E) |
| 2 | **扇形／弧段** | 繪製 → 扇弧 (A)；左欄 **弧｜扇**；`G` 在相關工具時切換 |
| 3 | **自選範圍匯出** | 「匯出 ▾」→ 框選匯出；預覽／PNG／SVG 只匯該區 |
| 4 | **匯出隱藏點** | 「匯出 ▾」內勾選（預設開） |
| 5 | **水平線／垂線** | 構造：點選後拖曳定長 |
| 6 | **雙網格** | 方格｜三角格（預設三角格＋網格開） |
| 7 | **自訂模板** | 多選 → 存為模板 |
| 8 | **長度沿邊傾斜** | 長度標註平行於邊、可讀翻正 |
| 9 | **快捷鍵可自訂** | `?`／`Ctrl+/`；可改鍵並存本機；衝突會標示 |
| 10 | **標籤避線** | 新建標籤自動偏離附近線／圓 |
| 11 | **對齊輔助** | 拖點／畫線時顯示水平／垂直參考線；近等長提示 |
| 12 | **深色畫布** | 僅編輯舒適用；**匯出仍白底黑線** |
| 13 | **最近檔＋自動備份** | 「最近 ▾」；定時備份；啟動可還原 |
| 14 | **優角／Reflex** | 記號 → 優角；畫 >180° 大弧；可標字母／度數 |
| 15 | **簡易座標圖** | 多曲線；對數底；軸數值；sin/cos/tan；圓一般式；曲線標籤；三角參數單位；**角度軸刻度**（π 直式分數／°）；原點只標 O；選取後拖角縮放 |
| 16 | **介面中／EN** | 頂欄 **中｜EN**；按鈕與工具提示同步；畫布數學不變 |
| 17 | **預設縮放 2×** | 首次開啟／清除／無相機 JSON；有存相機則沿用 |
| 18 | **離開警告** | 僅未儲存編輯時；空白／已存／剛還原備份不提示 |

### 座標對話框（摘要）

- **角度軸刻度**（預設關）：π／° 刻度；關閉還原數字刻度與視窗。
- **三角參數單位**：只影響 sin／cos／tan 的 Bx+C。
- 排版約 920px 兩欄；1–3 條曲線通常無列表捲軸。
- 弧度 π 刻度為直式分數；軸數值略過 ≈0。

## 簡短操作流程

1. 開啟 `index.html` 或 `simple-diagram-standalone.html`（標題應見 **Simple Diagram · v13.2.1**）。
2. 左側選工具；「匯出 ▾」預覽或存檔。
3. Chrome／Edge 存檔可選資料夾；匯出不受深色畫布影響。
4. AI／自動化：見 [`diagram-format.md`](diagram-format.md) 與 README「AI / Automation」（JSON＋ops，不模擬 UI）。
