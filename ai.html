3. 標籤／自由文字 / Labels & free text

addLabel：必填 pointId, text；可選 ox, oy, size, id, offsetDist, auto／autoOffset。

  • ox/oy = 相對該點的世界座標偏移（與 x/y 同單位；+y 向下）
  • 兩邊都沒給數字，或設 auto:true／autoOffset:true（而且 ox、oy 都不是數字）時，不使用固定 (0,-14)。距離 dist = offsetDist ?? 16。ox = round(dist·cos θ)，oy = round(dist·sin θ)。
  • 方向：每條以該點為端點的線段，角度是從本點指向另一端的 atan2(dy, dx)。≥2 條取最大角隙（多邊形外角）再平分；角隙一樣大時取較向上（−y）的平分線，再取較向右。恰好 1 條取反方向（θ+π）。沒有線段、也不在圓上：維持 (0, -14)。
  • 點在圓上（到圓心距離 ≈ 半徑，容差 max(1e-3, 1e-6·r)）時，圓心→點的向外法線是優先方向，讓標籤留在圓外。沒有線段時就沿這條法線（多圓取單位向量平均；互相抵消則用第一個）。有線段時，只有算出的方向朝圓內才改用法線。橢圓與扇形不算圓。
  • 任一軸是數字（含 0）：結果上記 _autoOffset:false，該數字原樣保留，之後加線段也不改。沒給的那一軸仍用舊預設（ox→0、oy→-14）。沒有數字偏移時記 _autoOffset:true，並寫可存檔的 autoOffset:true。_autoOffset 不進 JSON；載入後由 autoOffset 重建再重算。applyOps 結束時，以及有新線段接到該點時，重算自動標籤。明確數字經存檔再載入不變。
  • 每點一個標籤（後寫覆蓋）

addPoint、addMidpoint、addRatioPoint、addIntersection、addTriangleCenter：label:true（文字＝點 id）或 label 為非空字串，且點不是 hidden:true，會順便建立 addLabel。可選 labelOx／labelOy；省略則走自動偏移。addTriangleCenter 既有的數字 ox／oy 仍算明確偏移。addIntersection 同時給 id2 時只標第一個點（穩定序的第一個）。

addText（別名 addCaption）：必填 x, y, text；可選 id, size, align（center｜left｜right，預設 center）, bold（預設 false）。

輕量數學文字（addLabel、addText、座標軸名 axisLabelX/axisLabelY、曲線 label）：字串含 _ 或 ^ 才解析。_5／_{16} 下標，^2／^{n} 上標；log ln sin cos tan 直立，單字母變數斜體。沒有 _／^ 的純文字（含中文、"P"）維持原本樣式，不會整段改斜體。
Light math runs only when the string contains _ or ^. Plain labels stay as they are today.

  • 自由文字，不綁 pointId；存於 texts[]；可選取／拖曳／刪除／匯出（含光暈）
  • Free-floating caption — not bound to a point; select/drag/delete/export/halo work.

5. 構造 / Construction

優先用宣告式構造 op（addMidpoint／addRatioPoint／addIntersection／addFoot），勿手算座標再 addPoint。
Prefer these construction ops over hand-calculated coordinates.

op必填可選 / tip
addMidpoint a+b 或 segmentId id, marker（同 addPoint）, hidden?: boolean（同 addPoint；true 不加標籤）, label／labelOx／labelOy（見 §3）, markEqual（預設 false；true → 建／標子線段 (a,id)+(id,b) 的 addEqualMark）, equalGroup（預設 0）, style（子線段）

5.1 三角形中心、方位角、圓餅圖

三個 op 都展開成既有的點、線、圓、填色、角弧與文字。沒有新欄位時，舊圖與舊 op 不變。退化（邊長過短或三點共線）只 console.warn 並跳過，不 throw。找不到的點 id 仍 throw。

addTriangleCenter（別名 addIncircle、addCircumcircle）。必填 a、b、c（頂點 id；addShape 的 KA 與裸字母照舊解析）。kind：incentre｜incenter（addIncircle 預設）｜circumcentre｜circumcenter（addCircumcircle 預設）｜centroid｜orthocentre｜orthocenter。addTriangleCenter 本身必填 kind。

  • 內心 I = (a·A + b·B + c·C) / (a+b+c)，a=|BC|、b=|AC|、c=|AB|。畫圓時半徑是 I 到直線 AB 的距離，圓通過該垂足。markTouchPoints:true 或 touchIds:["idAB","idBC","idCA"]（僅內心）會留下 AB、BC、CA 上的可見切點；否則垂足 hidden:true。
  • 外心用垂直平分線交點；畫圓時圓通過頂點 a。共線則跳過，不建圓、也不建外心。
  • 重心是三頂點平均，共線仍建立。垂心是 A 高（⊥ BC）與 B 高（⊥ CA）的交點；共線則跳過。
  • 可選中心 id、hidden、label（true＝文字為點 id，或非空字串；hidden:true 不加標籤）、labelOx／labelOy，以及既有的 ox／oy（數字＝明確偏移，見 §3）。drawCircle 在兩個別名預設 true，其餘預設 false。circleId、circleStyle 只在有畫圓時使用。

addBearing（別名 addCompass）。必填 at（別名 pointId）。northLen 預設 56，向北（−y）到隱藏箭尖；實線北段，箭尖另有兩小段實線箭頭。northLabel 預設 "N"；false 或 "" 不標。showCross 預設 false：在 at 加向東、向西、向南的短虛線刻度。to 才畫方位弧。from 預設 "N"，亦可 "S"｜"E"｜"W"。text 例如 "52°"。mode："acute"（預設，from 軸與 at→to 的劣角；N 52° E、S 38° W）｜"cw"（別名 "true"：一律從正北順時針量到 at→to；大於 180° 則 reflex:true）。arcSize 預設 16，且不會大於 northLen × 0.30（預設北長 56 時為 16）。見 §7。

addPieChart（別名 addPie）。必填 x、y 或 centerId，以及 slices（長度 ≥ 2）。r 預設 95。startDeg 預設 0（正東）；−90 是正北。clockwise 預設 true。idPrefix 可選。每一塊用 angle（度，原樣使用）或 value（依總和正規化成 360°）；每一塊都有 angle 時不當成 value。大於 180° 的塊，以及逆時針正好 180° 的塊，拆成兩份劣弧填色（既有扇形填色仍走劣弧）。整圓用一個 addCircle 當外框。label 放在角平分線上，半徑比例 labelRadiusRatio 預設 0.62，經 addText（沿用既有光暈）。同一塊同時有 label 與 angleText（別名 angleLabel，寫入仍是 angleText）或 rightAngle:true，而且 op 與該塊都沒有設定 labelRadiusRatio 時：類別標在外圈約 0.68r；扇角小於 45° 則把類別標推到餅外約 1.16r，並依左右半邊設 text-anchor（右半 left、左半 right）。角文放在內圈約 0.36r，離開圓心小弧。明確的 labelRadiusRatio（op 或該塊）仍只決定類別標半徑，不套這組內外分裂。只有類別、沒有角文時維持 0.62。angleText／angleLabel 在圓心加 addAngleArc（超過 180° 為優角）；圓心弧 size＝round(max(12, min(16, r × 0.19)))，可用 arcSize 覆蓋。rightAngle:true 為該塊加 addRightAngle。可選 pattern（hatch｜solid）與 opacity；未指定時實心用一組淺色、透明度 0.55。

10.7 可行區域 / Feasible region

addFeasibleRegion，或 addCoordPlot 的 feasibleRegion／feasibleRegions，或 addFill 帶 inequalities。必填 inequalities。省略 plotId 用最後一個座標圖；找不到圖：console.warn 並跳過，不拋錯。省略這些欄位時，舊座標圖與舊填色不變。

欄位預設說明
inequalities必填字串或物件陣列。解不出的那一條 console.warn 並跳過
plotId最後一個座標圖掛在哪張圖上
pattern"hatch"亦可 "solid"
hatchSpacing8省略時不寫入填色，繪製仍用 8

drawBoundariesfalsetrue 時為每條非軸邊界加曲線
domainClip[xmin,xmax,ymin,ymax][uMin,uMax,vMin,vMax]。顛倒的端點會對調

每條不等式正規化成半平面 A u + B v ≤ C（>=／> 變號）。字串接受 <= >= < > ≤ ≥、斜率式與一般式；* 可省略；分數寫 3/2 或 (3/2)。例：y <= 2x + 1、y >= -0.5x + 3、y < 1.5*x - 2、x + y <= 5、3x - 2y >= -6、2x + 3y - 12 <= 0、x >= 0、y > 1、y <= (3/2)x + 3、y <= 3/2 x + 3。

物件：{ "a": 1, "b": 1, "op": "<=", "c": 5, "drawLine"?: true, "style"?: "solid"|"dashed", "label"?: "L_1" } 表示 a x + b y op c。或 { "expr": "y <= 2x + 1", "label": "L_1" }。係數與 expr 同時有時用係數。

從 domainClip 的軸對齊矩形開始，Sutherland–Hodgman 逐條裁切。頂點 ≥ 3 且面積 > 1e-6 才做成一般多邊形填色。這些自動頂點與 mathPoints 一樣預設 hidden:true（不畫圓點，填色仍在）。世界座標 x = ox + u·xUnitPx、y = oy − v·yUnitPx（沒有分軸比例就用 unitPx）。空交集：警告且不加填色。嚴格 < > 仍按閉半平面裁，邊界改虛線。

10.8 曲線交點與曲線間面積 / Intersections and area

addCurveIntersection（別名 addPlotIntersection）把根做成 addPlotPoint。addAreaBetweenCurves，或 addFill 的 kind:"betweenCurves"，在兩條圖形之間做填色。省略 plotId 用最後一個座標圖。找不到圖、找不到曲線、沒有根：console.warn 並跳過，不拋錯。不呼叫這兩個 op、也不寫 kind:"betweenCurves" 時，舊座標圖與舊填色不變。

curve1／of1、curve2／of2 可以是曲線 id、曲線索引、"xAxis"（y=0）、"yAxis"（x=0），或內聯曲線 { "type": "line", "params": { "m": 1, "c": 1 } }。內聯曲線只用來求解，不會加進座標圖。addAreaBetweenCurves 的 curve1 必填；curve2 省略則是 "xAxis"。面積的 curve2 若是數字（含 0）表示水平線 y＝該數；也可以是 { "y": 2 } 這類水平線物件。交點 op 的數字仍是曲線索引，不是水平線。

欄位預設說明
domain視窗 [xmin,xmax] 與兩條曲線 domain 的交集交點只在這段找。顛倒的端點會對調。對數從 1e-4 起算
id自動選中的第一個根。多個根但只給 id 時，用 pick 或 nearU 選一個
id2／ids省略其餘的根。ids:["P","Q",…] 依 u 升序對上；若 |u1−u2|≤1e-4 再依 v 升序。多出來的根不命名就略過
pick"left""left"／"first"／0 最小 u；"right"／"last"；"second"／1；"top" 最大 v；"bottom" 最小 v。超出範圍就警告並跳過
nearU省略有數字時優先於 pick，取 u 最接近的根
點的外觀同 addPlotPointlabel、ox、oy、hidden、projectX、projectY、projectStyle、xTickLabel、yTickLabel、forceTickLabel、role、color 會傳到每一個選中的根。投影刻度與軸上已顯示的刻度重疊時，規則同 §10.6

直線、鉛直線、二次曲線用差的多項式代數求解（二次方程，必要時再拋光）。sin／cos／tan／exp／log／ln 在定義域上約 400 段取樣，變號則二分，並以牛頓把 |f1−f2| 收到 1e-7 以內。tan 跨過漸近線的正負號跳動不是根，會丟掉。圓這類非函數曲線不求，警告並跳過。

面積：寫了 domain:[a,b] 就在該段（再與視窗、曲線定義域求交）取 80 個步（落在 64–96），沿曲線 1 過去、沿曲線 2 回來，閉合成多邊形。頂點 hidden:true。省略 domain 時先求交點，至少要 2 個，否則警告並跳過；正好兩個就塗最左到最右，多於兩個就為每一段相鄰閉區間各塗一塊（中間再穿過的地方各自成區）。預設 pattern:"hatch"；省略 hatchSpacing 不寫入填色，繪製仍用 8。也可 "solid"、opacity、color、role。label（例如 "R"）放在面積形心，置中粗體 addText，沿用既有光暈。role／color 會傳到點、填色與形心文字。
