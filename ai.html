1. 產出什麼 / What to output

  • Ops 陣列（推薦）：[{ "op": "addPoint", … }, …]
  • 或完整圖檔：含 formatVersion、points、segments… 的物件
  • 也可 { "ops": [ … ] }

不要模擬滑鼠／UI。順序：先點／線／圓，再記號與填色。之後的 op 只能引用已有 id。
Do not click the UI. Points → edges → circles → marks/fills. Later ops may only reference existing ids.

2. 座標與視窗 / Coordinates & view

  • 世界座標；+y 向下
  • 建議落在畫面內：x ≈ 100–600，y ≈ 100–500（預設視窗中心約 view {x:400,y:300,scale:2}）。避免大／負座標除非刻意。
  • 點請給穩定 id（如 A、B、O）
  • 線段 style：solid（預設）｜dashed（隱藏邊）｜dotted（構造）｜dashdot

Prefer x≈100–600, y≈100–500 so pasted figures land on-screen. Default empty view centers near (400,300) at scale 2.

3. 標籤偏移 / Label offsets

addLabel：pointId、text；可選 ox、oy、size。

  • ox / oy = 相對該點的世界座標偏移（與點的 x/y 同一單位；+y 向下）
  • 預設 ox: 0、oy: -14（標籤略在點上方）
  • 每點一個標籤（後寫覆蓋）

4. 角記號 / Angle marks

op必填 / required可選 / optional
addRightAngle vertex, arm1, arm2（點 id） size
addAngleArc vertex, arm1, arm2 size, group (0/1), text, reflex (bool)
addReflex 同 addAngleArc 強制 reflex: true（優角 >180°）

arm1/arm2 是角兩邊上的點 id（不是線段 id）。

6. addShape（平面／立體）

相當於 UI「圖形」拖放：用原點 + 尺寸一次建立多點／線（或固體模板）。

欄位說明
kind見下表
x, y必填。平面：第一角／原點；立體：放置偏移 (dx/dy)
w 或 size必填 > 0。平面＝寬；立體＝整體縮放寬度
h平面高（可選；預設＝w）。立體忽略 h
style線段樣式（平面邊）
label / labels平面：自動標 A,B,… 或自訂字串陣列
idPrefix可選點／線 id 前綴

平面 kinds：square｜rect｜rhombus｜parallelogram｜trapezoid｜kite｜equilateral｜iso｜rightTri｜isoRight｜pentagon｜hexagon｜circle｜semicircle

  • circle：中心 (x,y)，半徑點 (x+w,y)
  • semicircle：直徑端點 (x,y)→(x+w,y)，中點為圓心
  • rightTri：直角在 (x,y)，直角邊 w（水平）與 h（向下）
  • square/rect：角 (x,y) 起向右／下

立體 kinds（內建投影模板；只用 x,y,w）：cube｜cuboid｜rectPrism｜frustum｜tetra｜pyramid｜triPrism｜cylinder｜cone

別名：rectPrism≡prism；iso≡isosceles；rightTri≡right／rightTriangle。

[
  { "op": "addShape", "kind": "rightTri", "x": 160, "y": 320, "w": 140, "h": 100, "label": true }
]

7. addFill

可選共通：color（預設 #666666）、opacity（預設 0.2）。白色挖空：color:"#ffffff", opacity:1。

kind必填備註
polygon（預設） pointIds ≥3 點 id 亦接受 points
sector centerId, startId, endId 可選 circleId；扇形（兩半徑＋弧）
segment startId, endId + (circleId 或 centerId) 弓形（弦＋弧）
polyArc pointIds ≥2 + centerId, startId, endId 折線再以弧閉合；可選 circleId
pathFill edges ≥2 邊：{type:"line",a,b} 或 {type:"arc",centerId,from,to,circleId?}

9. 其他常用 ops

op必填參數
addPointx, y（可選 id, marker）
addSegmenta, b 點 id
addCirclecenterId, throughId
addFootpointId + segmentId（或線上兩點 a/b）
insertTemplateid：circleGeom｜circleCenter｜altBase…；可選 dx, dy, scale
setViewx, y, scale（視窗中心／縮放）

10. 使用者怎麼貼 / How to paste

  1. 開啟 Simple Diagram
  2. 頂欄 貼上 JSON
  3. 貼上 → 套用（可 Ctrl+Z）

11. 規則 / Rules

  • 只輸出 JSON（可包 markdown 程式碼塊；App 會剝掉）
  • id 唯一；數字座標用有限數字（勿字串）
  • 完整圖檔需含 points 等陣列（同 App「儲存」）
