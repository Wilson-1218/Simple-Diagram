1. 產出什麼 / What to output

  • Ops 陣列（推薦）：[{ "op": "addPoint", … }, …]
  • 或完整圖檔：含 formatVersion、points、segments… 的物件
  • 也可 { "ops": [ … ] }

不要模擬滑鼠／UI。使用者貼上後 App 會套用並更新畫布。
Do not click the UI. User pastes; the app applies and redraws.

2. 座標 / Coordinates

  • 世界座標；+y 向下（畫布）
  • 點請給穩定 id（如 A、B、O）
  • 隱藏邊："style": "dashed"；構造線："dotted"

3. 常用 ops（最小例）

[
  { "op": "addPoint", "id": "A", "x": 120, "y": 280 },
  { "op": "addPoint", "id": "B", "x": 320, "y": 280 },
  { "op": "addPoint", "id": "C", "x": 120, "y": 120 },
  { "op": "addSegment", "id": "AB", "a": "A", "b": "B" },
  { "op": "addSegment", "id": "BC", "a": "B", "b": "C" },
  { "op": "addSegment", "id": "CA", "a": "C", "b": "A" },
  { "op": "addRightAngle", "vertex": "A", "arm1": "B", "arm2": "C" },
  { "op": "addLabel", "pointId": "A", "text": "A", "ox": -16, "oy": 14 },
  { "op": "addLabel", "pointId": "B", "text": "B", "ox": 14, "oy": 14 },
  { "op": "addLabel", "pointId": "C", "text": "C", "ox": -16, "oy": -14 },
  { "op": "addFill", "kind": "polygon", "pointIds": ["A","B","C"], "opacity": 0.15 }
]

4. 更多 ops（簡表）

  • addCircle — centerId + throughId
  • addShape — kind：正方形／三角／圓… 或立體 cube、frustum…
  • addFoot — 垂足：pointId + segmentId
  • addFill — kind：polygon｜sector｜segment（白色挖空：color:"#ffffff", opacity:1）
  • insertTemplate — id：circleGeom｜circleCenter｜altBase…
  • setView — { "x", "y", "scale" }

順序：先點／線／圓，再記號與填色。之後的 op 只能引用已有 id。

5. 使用者怎麼貼 / How the user pastes

  1. 開啟 Simple Diagram（本站）
  2. 按頂欄 貼上 JSON
  3. 貼上 AI 產出的 JSON → 套用

可 Ctrl+Z 復原。錯誤會以中／EN 顯示。

6. 規則 / Rules

  • 只輸出 JSON（可包在 markdown 程式碼塊裡，App 會剝掉）
  • id 唯一；線段的 a/b 必須是已有點
  • 數字座標用有限數字（勿用字串）
  • 完整圖檔需像 App「儲存」的結構（含 points 等陣列）
