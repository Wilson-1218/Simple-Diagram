2. 座標與視窗 / Coordinates & view

  • 世界座標；+y 向下
  • 建議圖形落在 x ≈ 100–600，y ≈ 100–500（預設 view {x:400,y:300,scale:2}）
  • 線段 style：solid｜dashed（隱藏邊）｜dotted（構造）｜dashdot
  • setView：x, y（視窗中心世界座標）, scale > 0

3. 標籤／自由文字 / Labels & free text

addLabel：必填 pointId, text；可選 ox, oy, size, id。

  • ox/oy = 相對該點的世界座標偏移（與 x/y 同單位；+y 向下）
  • 預設 ox:0, oy:-14；每點一個標籤（後寫覆蓋）

addText（別名 addCaption）：必填 x, y, text；可選 id, size, align（center｜left｜right，預設 center）, bold（預設 false）。

輕量數學文字（addLabel、addText、座標軸名 axisLabelX/axisLabelY、曲線 label）：字串含 _ 或 ^ 才解析。_5／_{16} 下標，^2／^{n} 上標；log ln sin cos tan 直立，單字母變數斜體。沒有 _／^ 的純文字（含中文、"P"）維持原本樣式，不會整段改斜體。
Light math runs only when the string contains _ or ^. Plain labels stay as they are today.

  • 自由文字，不綁 pointId；存於 texts[]；可選取／拖曳／刪除／匯出（含光暈）
  • Free-floating caption — not bound to a point; select/drag/delete/export/halo work.

5. 構造 / Construction

優先用宣告式構造 op（addMidpoint／addRatioPoint／addIntersection／addFoot），勿手算座標再 addPoint。
Prefer these construction ops over hand-calculated coordinates.

op必填可選 / tip
addMidpoint a+b 或 segmentId id, marker（同 addPoint）, hidden?: boolean（同 addPoint）, markEqual（預設 false；true → 建／標子線段 (a,id)+(id,b) 的 addEqualMark）, equalGroup（預設 0）, style（子線段）
addRatioPoint a+b 或 segmentId（方向 a→b） id, marker, hidden?: boolean；比例：m+n（P=(nA+mB)/(m+n)，m+n≠0）或 t（P=A+t(B−A)）；兩者皆有時 t 優先；預設 t=0.5（可延伸線外）
addIntersection of1, of2 各為既有線段／圓 id，或內嵌 {"type":"line","a":"A","b":"C"}。id；兩交點時可 id2（穩定序：x 升，|Δx|≤1e-4 再 y 升）。extendLines 預設 true（無限線）；false → 交點須在線段 [0,1]。消歧（兩點且無 id2）：(1) avoidPointId 取較遠 (2) nearPointId 取較近 (3) pick：left／right／top｜above／bottom｜below／0｜first／1｜second（+y 向下）。支援 line×line、line×circle、circle×circle。無交點 → console.warn 並略過（不 throw）。hidden?: boolean（同 addPoint）
addFoot pointId +（segmentId 或 a/b） footId/id, drawSegment（預設 true＝畫高）, style, label/labelText, marker（預設 "foot"；false 關閉）

5.1 三角形中心、方位角、圓餅圖

三個 op 都展開成既有的點、線、圓、填色、角弧與文字。沒有新欄位時，舊圖與舊 op 不變。退化（邊長過短或三點共線）只 console.warn 並跳過，不 throw。找不到的點 id 仍 throw。

addTriangleCenter（別名 addIncircle、addCircumcircle）。必填 a、b、c（頂點 id；addShape 的 KA 與裸字母照舊解析）。kind：incentre｜incenter（addIncircle 預設）｜circumcentre｜circumcenter（addCircumcircle 預設）｜centroid｜orthocentre｜orthocenter。addTriangleCenter 本身必填 kind。

  • 內心 I = (a·A + b·B + c·C) / (a+b+c)，a=|BC|、b=|AC|、c=|AB|。畫圓時半徑是 I 到直線 AB 的距離，圓通過該垂足。markTouchPoints:true 或 touchIds:["idAB","idBC","idCA"]（僅內心）會留下 AB、BC、CA 上的可見切點；否則垂足 hidden:true。
  • 外心用垂直平分線交點；畫圓時圓通過頂點 a。共線則跳過，不建圓、也不建外心。
  • 重心是三頂點平均，共線仍建立。垂心是 A 高（⊥ BC）與 B 高（⊥ CA）的交點；共線則跳過。
  • 可選中心 id、hidden、label、ox、oy。drawCircle 在兩個別名預設 true，其餘預設 false。circleId、circleStyle 只在有畫圓時使用。

addBearing（別名 addCompass）。必填 at（別名 pointId）。northLen 預設 56，向北（−y）到隱藏箭尖；實線北段，箭尖另有兩小段實線箭頭。northLabel 預設 "N"；false 或 "" 不標。showCross 預設 false：在 at 加向東、向西、向南的短虛線刻度。to 才畫方位弧。from 預設 "N"，亦可 "S"｜"E"｜"W"。text 例如 "52°"。mode："acute"（預設，from 軸與 at→to 的劣角；N 52° E、S 38° W）｜"cw"（別名 "true"：一律從正北順時針量到 at→to；大於 180° 則 reflex:true）。arcSize 預設 22。見 §7。

addPieChart（別名 addPie）。必填 x、y 或 centerId，以及 slices（長度 ≥ 2）。r 預設 95。startDeg 預設 0（正東）；−90 是正北。clockwise 預設 true。idPrefix 可選。每一塊用 angle（度，原樣使用）或 value（依總和正規化成 360°）；每一塊都有 angle 時不當成 value。大於 180° 的塊，以及逆時針正好 180° 的塊，拆成兩份劣弧填色（既有扇形填色仍走劣弧）。整圓用一個 addCircle 當外框。label 放在角平分線上，半徑比例 labelRadiusRatio 預設 0.62，經 addText（沿用既有光暈）。angleText 在圓心加 addAngleArc（超過 180° 為優角）。rightAngle:true 為該塊加 addRightAngle。可選 pattern（hatch｜solid）與 opacity；未指定時實心用一組淺色、透明度 0.55。

6. 圓件／切線 / Circle parts

皆需已有 circleId。方向可用點 id，或 angle（弧度）／deg（度）；預設角 0＝正 x。

op必填方向／尺寸
addTangentcircleIdtouchId｜pointId｜angle｜deg；長度 halfLen（半長，預設 40）或 length（全長）；可選 aId, bId, style, order
addRadiuscircleIdthroughId 或 angle/deg（缺則建圓周點）
addDiametercircleId方向 angle/deg/throughId；建兩端點
addChordcircleId兩端：startId+endId（或 a/b），或 angle0/angle1，或 deg0/deg1

addTangent 端點空間對應（預設 order:"leftToRight"）：aId＝左側（較小 x），bId＝右側（較大 x）；若切線近鉛垂（|Δx|≤1e-3），則 aId＝上方（較小 y）、bId＝下方。例：圓底切點的水平切線 → a 在左、b 在右（再接直角／弧時用 a／b 不會左右顛倒）。可選 order:"ccw" 改為沿幾何切向（−sin θ, cos θ）不交換。Default leftToRight: aId left / bId right; nearly vertical → aId above.

8. 填色 / addFill

可選：color（預設 #666666；hatch 預設 #111111）, opacity（預設 0.2；hatch 預設 1）, pattern：solid（預設）｜hatch（同向斜短線，考試棒陰影）, hatchSpacing。白色挖空：color:"#ffffff", opacity:1（僅其他複合遮罩；兩弧＋一邊請用 pathFill）。暗色畫布上，未指定或預設深色 hatch（#111111/#000000）會以淺 slate（如 #94a3b8）顯示；白紙 SVG／PNG 匯出仍用 #111111。

polygon（預設）pointIds ≥3亦接受 points。或 mathPoints:[[u,v],…]＋可選 plotId（預設最後一個座標圖），依該圖比例換成世界頂點後成為一般多邊形填色（自動頂點預設 hidden:true，見 §10.6；pattern 仍可用 hatch 或實心／透明度）

9. addShape

一次放平面／立體圖形（UI「圖形」拖放的 JSON 版）。

欄位說明
kind見下
x, y必填。平面＝第一角／原點；立體＝放置偏移
w 或 size必填 >0。平面＝寬；立體＝縮放寬度
h平面高（可選＝w）。立體＝視覺高度（包圍盒高）；省略則維持現有比例（與只給 w 時的頂點相同）
style, label/labels, idPrefix可選

平面：square rect rhombus parallelogram trapezoid kite equilateral iso rightTri isoRight pentagon hexagon circle semicircle

立體：cube cuboid rectPrism frustum tetra pyramid triPrism cylinder cone

  • rightTri：直角在 (x,y)，水平腿 w、向下腿 h
  • circle：心 (x,y)，半徑點 (x+w,y)
  • 別名：prism→rectPrism；right/rightTriangle→rightTri
  • 立體會自動建立頂點標籤（A…），並用虛線表示隱藏邊。省略 label／labels 時仍標字母。idPrefix（如 "K"）把頂點 id 改成 K0…、線段 id 改成 Ks0…（與平面形相同）。labels:false 或 label:false 略過頂點字母（兩者任一為 false 即略過）。
  • h：所有立體 kinds 的視覺高度。省略時 x／y 用同一個縮放，頂點與 v13.5.40 相同。
  • pyramid／cone 可選 apexOffset:[dx,dy]（世界單位）平移頂點 V，使它不必在底心正上方（例如移到某一底邊頂點上方，做成直角側棱）。
  • includeBaseCenter:true（預設 false）在底心加點，id 為 O，有 idPrefix 時為 {prefix}O（K → KO）。drawHeight:true 從該點到 V 畫點線。
  • cylinder／cone 可選 waterLevel（0 < waterLevel < 1）。0 在較低的底、1 在圓柱上底或圓錐頂點；該高度的局部半徑畫水平橢圓，後一半虛線、前一半實線。

Solids auto-create vertex letters + hidden (dashed) edges. idPrefix prefixes vertex ids (K0…) and segment ids (Ks0…). Omit h to keep today's proportions. apexOffset, includeBaseCenter (KO), drawHeight, and waterLevel are optional.

9.1 立體頂點順序（引擎實際命名）

索引 0 起，與 idPrefix 的 K0… 對齊。畫布 +y 向下，所以模板裡較小的格子 y 在圖上較高。

kind順序
cuboid／cube底 A,B,C,D，頂 E,F,G,H
rectPrismA,B,C,D,E,F（六頂點草圖：A–D 一面，E 在 A 之上、F 在 B 之上）
frustum下底 A,B,C,D，上底 E,F,G,H
tetraA 為上方頂點，B,C,D 為底
pyramid底 A,B,C,D，頂點 V
triPrism前三角 A,B,C，後三角 D,E,F
cylinder下橢圓心 O、右緣、下緣、左緣，上橢圓心 O′、右緣、下緣、左緣（只標 O 與 O′）
cone底心 O、右緣、下緣、左緣、頂點 V

字母別名：標籤是 A、B、C…、V，點 id 仍是 K0…。之後的 addSegment、addRightAngle 等接受 {idPrefix}{字母}（KA、KC、KV），對到該字母的頂點（角錐／長方體的 C 是 K2，角錐的 V 是 K4）。那個字母還不是已有點 id 時，裸字母 A…V 也對到這個圖形的頂點。呼叫端已經建立的點不會被換掉：先有點 C 時，C 仍是那個點，KC 仍是 C 頂點。有畫出的 labels 覆寫時，別名跟畫面上的字母；labels:false 時仍用模板字母。多個圖形共用同一個裸字母時，後放的圖形生效；前綴別名（KC／LC）各自對到自己的頂點。真正的點 id（例如底心 KO）永遠優先於同名別名。

idPrefix:"K" keeps ids K0…. Later ops may pass KC or, when no point C exists, bare C. A caller-created point is never replaced. Shown label letters win; with labels:false the template letters (A…H, V) still alias.

9.2 addRightAngle 的 3D 標記

預設 mode:"2d"（可省略）：沿兩臂方向的紙上記號，邊長跟匯出墨水（約數毫米），與以往相同。mode:"3d" 或 skew:true：取 (arm1−vertex)、(arm2−vertex) 的單位向量，邊長 size（世界單位），畫出經過 vertex + s·u1、vertex + s·u1 + s·u2、vertex + s·u2 的平行四邊形。兩臂在畫面上不垂直時，這是斜的平行四邊形，不是那枚較小的 2D 方標記。

9.3 add3DPolyhedron

用面的外向法線決定實線／虛線，不要套用角錐模板那組寫死的隱藏邊。3D 軸：+X 右、+Y 上、+Z 朝觀察者（旋轉前）。yawDeg 繞 Y（預設 35），pitchDeg 再繞 X（預設 20，正值把 +Y 傾向觀察者）。scale 預設 40。origin:[ox,oy] 是投影後原點的世界座標。面可以順時針或逆時針。引擎用 Newell 算法線後，取全體頂點形心 G 與面心 Fc；若 (Fc − G) · n < 0 就把 n 翻成朝外，所以不要求呼叫端把面收成逆時針。旋轉後，這條朝外法線的視空間 Z > 0 為正面。至少屬於一個正面的邊（含輪廓）為 solid；只屬於背面的邊為 dashed。

idPrefix:"K" 時頂點 id 為 KA、KB…（前綴接上頂點名字），線段 Ks0…。labels:false 略過字母；省略則標頂點名字。

10. 座標圖 / Coordinate plots ★

When：畫函數／圓／三角曲線。先 addCoordPlot，再可 addCurve 追加。

10.7 可行區域 / Feasible region

addFeasibleRegion，或 addCoordPlot 的 feasibleRegion／feasibleRegions，或 addFill 帶 inequalities。必填 inequalities。省略 plotId 用最後一個座標圖；找不到圖：console.warn 並跳過，不拋錯。省略這些欄位時，舊座標圖與舊填色不變。

欄位預設說明
inequalities必填字串或物件陣列。解不出的那一條 console.warn 並跳過
plotId最後一個座標圖掛在哪張圖上
pattern"hatch"亦可 "solid"
hatchSpacing8省略時不寫入填色，繪製仍用 8
color, opacity同 hatch／solid 填色hatch 預設 #111111、不透明
label省略例如 "R"。面積形心、世界座標、置中粗體 addText（既有光暈）。含 _／^ 走輕量數學文字
drawBoundariesfalsetrue 時為每條非軸邊界加曲線
domainClip[xmin,xmax,ymin,ymax][uMin,uMax,vMin,vMax]。顛倒的端點會對調

每條不等式正規化成半平面 A u + B v ≤ C（>=／> 變號）。字串接受 <= >= < > ≤ ≥、斜率式與一般式；* 可省略；分數寫 3/2 或 (3/2)。例：y <= 2x + 1、y >= -0.5x + 3、y < 1.5*x - 2、x + y <= 5、3x - 2y >= -6、2x + 3y - 12 <= 0、x >= 0、y > 1、y <= (3/2)x + 3、y <= 3/2 x + 3。

物件：{ "a": 1, "b": 1, "op": "<=", "c": 5, "drawLine"?: true, "style"?: "solid"|"dashed", "label"?: "L_1" } 表示 a x + b y op c。或 { "expr": "y <= 2x + 1", "label": "L_1" }。係數與 expr 同時有時用係數。

從 domainClip 的軸對齊矩形開始，Sutherland–Hodgman 逐條裁切。頂點 ≥ 3 且面積 > 1e-6 才做成一般多邊形填色。這些自動頂點與 mathPoints 一樣預設 hidden:true（不畫圓點，填色仍在）。世界座標 x = ox + u·xUnitPx、y = oy − v·yUnitPx（沒有分軸比例就用 unitPx）。空交集：警告且不加填色。嚴格 < > 仍按閉半平面裁，邊界改虛線。

drawBoundaries: true，或該條 drawLine: true，會加一條座標曲線，但不加軸線 x=0 或 y=0。<= >= ≤ ≥ 實線；< > 虛線；寫了 style 就用它。斜線是 type:"line"；鉛直線（如 x <= 4）是 type:"vline"、params.x。每條 label（如 "L_1"）成為曲線自訂文字，下標可用。曲線畫滿座標圖視窗。

{
  "op": "addCoordPlot",
  "id": "plot1",
  "ox": 260, "oy": 360, "unitPx": 36,
  "xmin": -1, "xmax": 6, "ymin": -1, "ymax": 7,
  "feasibleRegion": {
    "inequalities": ["y <= 1.5x + 3", "2x + 3y <= 22", "y >= 0"],
    "pattern": "hatch",
    "hatchSpacing": 8,
    "label": "R",
    "drawBoundaries": true
  }
}

addFeasibleRegion / addFill with inequalities clip half-planes to a hatch polygon on the coord plot. Omit the field and the previous plot is unchanged. Strict inequalities stay closed for the fill and draw a dashed boundary. Axis lines x=0 and y=0 are not added as curves.
