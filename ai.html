1. 產出什麼 / What to output

  • Ops 陣列（推薦）：[{ "op": "addPoint", … }, …]
  • 或 { "ops": [ … ] }
  • 或完整圖檔（含 formatVersion、points…）

不要模擬 UI 點擊。順序：點／線／圓 → 記號／填色／曲線。之後的 op 只能引用已有 id。
No UI clicking. Points → edges → circles → marks/fills/curves.

已知 ops（36，含別名）：addPoint addSegment addLabel addCircle addEllipse addSector addFill addShape addFoot addTangent addRadius addDiameter addChord addRightAngle addAngleArc/addArc addReflex addParallelMark/addParallel addEqualMark/addEqual addLengthLabel/addLength addMidTick addCoordPlot addCurve alignPoints distributePoints equalizeSegments insertTemplate/addTemplate setView setMeta setLayers movePoint remove

UI ↔ op：工具列 ⊥ 座標＝addCoordPlot（＋addCurve）。沒有 addCoordMark 這類 op 名。
Rail tool ⊥ 座標 / Axes maps to addCoordPlot (+ addCurve). There is no addCoordMark.

2. 座標與視窗 / Coordinates & view

  • 世界座標；+y 向下
  • 建議圖形落在 x ≈ 100–600，y ≈ 100–500（預設 view {x:400,y:300,scale:2}）
  • 線段 style：solid｜dashed（隱藏邊）｜dotted（構造）｜dashdot
  • setView：x, y（視窗中心世界座標）, scale > 0

3. 標籤 / Labels

addLabel：必填 pointId, text；可選 ox, oy, size, id。

  • ox/oy = 相對該點的世界座標偏移（與 x/y 同單位；+y 向下）
  • 預設 ox:0, oy:-14；每點一個標籤（後寫覆蓋）

4. 基本幾何 / Core geometry

op必填可選 / tip
addPointx, yid, marker（"x"｜"foot"）
addSegmenta, b（點 id）id, style
addCirclecenterId, throughIdid, style — 半徑＝兩點距離
addEllipsecenterId, rxId, ryIdstyle, backDashed（3D 背弧）— 軸對齊
addSectorcenterId, startId, endIdmode："arc"（預設）｜"sector"（含兩半徑）
movePointid, x, ymarker
removetype, idtype：point｜segment｜label｜circle｜ellipse｜sector｜fill｜coordPlot｜rightAngle｜angleArc｜midTick｜parallelMark｜equalMark｜lengthLabel

5. 構造 / Construction

需求JSON 做法
垂足 foot addFoot：必填 pointId +（segmentId 或 線兩端 a/b）。可選 footId, drawSegment（預設 true＝畫高）, style, label/labelText, marker（預設 "foot"；false 關閉）
中點／比例分點 無專用 op。自行算座標 addPoint + addLabel。比例記號：先建點，再 addMidTick {segmentId, pointId}（短劃；中點工具本身不畫劃）
兩線交點／水平線／鉛垂線 無專用 op（UI only）。交點：算交點座標後 addPoint。水平／鉛垂：addPoint + addSegment（同 y 或同 x）

UI-only（無同名 JSON op）：交點 intersect、中點工具 midTick、比例 ratio、水平 horizontal、鉛垂 perpendicular — 用座標算出後 addPoint/addSegment。
不是 UI-only：⊥ 座標 → 用 addCoordPlot / addCurve（見 §10）。勿臆造 addCoord／addCoordMark。

6. 圓件／切線 / Circle parts

皆需已有 circleId。方向可用點 id，或 angle（弧度）／deg（度）；預設角 0＝正 x。

op必填方向／尺寸
addTangentcircleIdtouchId｜pointId｜angle｜deg；長度 halfLen（半長，預設 40）或 length（全長）；可選 aId, bId, style
addRadiuscircleIdthroughId 或 angle/deg（缺則建圓周點）
addDiametercircleId方向 angle/deg/throughId；建兩端點
addChordcircleId兩端：startId+endId（或 a/b），或 angle0/angle1，或 deg0/deg1

7. 記號 / Marks

op必填可選
addRightAnglevertex, arm1, arm2（點 id）size
addAngleArc＝addArc同上size, group（0 單／1 雙）, text, reflex
addReflex同角弧強制 reflex:true（優角）
addParallelMark＝addParallelsegmentIdgroup 0/1, side ±1
addEqualMark＝addEqualsegmentIdgroup, side
addLengthLabel＝addLengthsegmentIdtext, side, style（text｜dim｜arcs）, orient（tilt｜horizontal）, size
addMidTicksegmentIdpointId（比例分點短劃）

arm1/arm2 是角兩邊上的點 id，不是線段 id。

8. 填色 / addFill

可選：color（預設 #666666）, opacity（預設 0.2）。白色挖空：color:"#ffffff", opacity:1。

kind必填tip
polygon（預設）pointIds ≥3亦接受 points
sectorcenterId, startId, endId可選 circleId
segmentstartId, endId + (circleId|centerId)弓形
polyArcpointIds ≥2 + centerId, startId, endId折線＋弧閉合
pathFilledges ≥2{type:"line",a,b} 或 {type:"arc",centerId,from,to,circleId?}

9. addShape

一次放平面／立體圖形（UI「圖形」拖放的 JSON 版）。

欄位說明
kind見下
x, y必填。平面＝第一角／原點；立體＝放置偏移
w 或 size必填 >0。平面＝寬；立體＝縮放寬度
h平面高（可選＝w）。立體忽略 h
style, label/labels, idPrefix可選

平面：square rect rhombus parallelogram trapezoid kite equilateral iso rightTri isoRight pentagon hexagon circle semicircle

立體：cube cuboid rectPrism frustum tetra pyramid triPrism cylinder cone

  • rightTri：直角在 (x,y)，水平腿 w、向下腿 h
  • circle：心 (x,y)，半徑點 (x+w,y)
  • 別名：prism→rectPrism；right/rightTriangle→rightTri

10. 座標圖 / Coordinate plots ★

When：畫函數／圓／三角曲線。先 addCoordPlot，再可 addCurve 追加。
UI 工具列 ⊥ 座標 開的就是這組 op（不是獨立的「座標記號」op）。

10.1 addCoordPlot

欄位必填？預設 / 說明
ox, oy必填原點在世界座標的位置（建議落在畫面內，如 280, 320）
unitPx可選每單位像素，預設 40
xmin xmax ymin ymax可選預設 −2…6 / −2…6（數學座標；y 向上為正於軸上）
axisLabelX axisLabelY可選預設 "x" / "y"
showOrigin可選預設 true
showTicks可選預設 true — 刻度線（UI「顯示軸上刻度與數值」關時一併關）
showTickLabels可選預設 true — 軸上數字；設 false 時繪製／匯出亦隱藏刻度線（軸線與 O 仍在）
xAngleUnit可選"rad"（預設）｜"deg" — 影響 sin/cos/tan 的 x
angleAxisOn可選預設 false — 角度軸刻度模式
curves可選建立時一併加入的曲線陣列
id可選之後 addCurve.plotId 用

Plot 數學 y 向上；世界畫布仍 +y 向下 — 引擎會轉換。把 ox,oy 放在建議世界範圍內。

10.2 曲線 type 與 params

typeparams（預設）公式意涵
linem:-1, c:4y = mx + c
quada:1, b:0, c:0y = ax² + bx + c
log（別名 log10）a:1, base:10y = a·log_base(x)
lna:1y = a·ln(x)
expa:1, b:ey = a·bˣ
circle見下圓
sin cos tanA:1, B:1, C:0, D:0y = A·f(Bx+C)+D；x 單位見 xAngleUnit

circle params：

  • circleForm："general"（預設）｜"standard"｜"center"
  • general：D, E, F（x²+y²+Dx+Ey+F=0）；預設 D0 E0 F−4
  • center／standard：h, k, r（或 r2）

10.3 曲線標籤 label

欄位說明
showbool，預設 false
kind"formula"（預設）｜"custom"
formulaMode"algebraic"｜"numeric"
customTextkind=custom 時文字
t, n沿曲線位置／法向偏移（t∈[0,1]，n∈[−6,6]）

11. 對齊／圖層／meta

op參數
alignPointspointIds ≥2；axis：left｜center｜right｜top｜middle｜bottom
distributePointspointIds ≥3；axis：x｜y

helpers＝記號／標籤層；預設 helpersLock:true（跟著幾何，解鎖後可拖）。

12. 模板與 macros

12.1 insertTemplate＝addTemplate

必填 id；可選 dx, dy, scale, cellSize。

  • Templates 選單：僅「我的／Saved」使用者模板（無內建組合）
  • insertTemplate id（AI／完整目錄，皆 ui:false）：rightTri isoTri genTri parallelogram trapezoid pentagon + 全部固體 id（同 addShape 立體）

12.2 Macros（MCP run_macro／CLI；回傳 ops 可貼上）

macro主要 params
drawRightTrianglea, b（腿長）, origin:{x,y}, labels, style
drawFrustumdx, dy, scale
drawCircleWithTangentr, cx/cy 或 origin, halfLen
drawCuboid / drawCubesize 或 scale, dx, dy

瀏覽器「貼上 JSON」吃的是 ops 陣列，不是 macro 名。本機 MCP 可用 run_macro；或把 macro 展開後的 ops 貼上。

14. 規則 / Rules

  • 只輸出 JSON（可包 markdown 程式碼塊；App 會剝掉）
  • id 唯一；數字用有限 number（勿字串）
  • 無 stroke-width 欄位 — 只用 style 虛實
  • 完整圖檔需含 points 等陣列（同「儲存」）
